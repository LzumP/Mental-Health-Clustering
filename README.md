# Mental Health in Tech – PCA und K-Means
Dieses Projekt analysiert den OSMI-Datensatz „Mental Health in Tech Survey 2016“.

# prep_1.py
Bereitet die Daten vor. Dabei werden fehlende Werte behandelt, uneinheitliche Angaben bereinigt, Kategorien per Mapping in Zahlen umgewandelt und Berufspositionen per One-Hot-Encoding codiert.

# pca_kmeans.py
Standardisiert die Daten, reduziert die Dimensionen mit PCA und bildet vier Cluster mit K-Means. Zusätzlich werden Elbow-Diagramm, Clustergrößen und eine PCA-Visualisierung erstellt.

# Datensatz
https://www.kaggle.com/datasets/osmi/mental-health-in-tech-2016/data
